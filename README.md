# بوابة الطالب الإلكترونية - جامعة الزعيم الأزهري (المرحلة الأولى)

## خطوات التشغيل السريع:

1. فك الضغط عن المجلد وافتحه في موجه الأوامر (Terminal / CMD) أو محرر الأكواد (VS Code).
2. قم بتثبيت الحزم والمكتبات المطلوبة عبر الأمر:
   ```bash
   npm install
   ```
3. لتشغيل السيرفر في وضع التطوير:
   ```bash
   npm run dev
   ```
4. افتح المتصفح وتوجه إلى الرابط:
   `http://localhost:5000`
